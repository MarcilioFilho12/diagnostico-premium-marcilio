# MarcílioDev · Diagnóstico Premium

Formulário estratégico em etapas para descobrir posicionamento, narrativa, estrutura e direção criativa de um site premium.

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).

## O que tem

- 4 etapas: Descoberta → Conceito → Experiência → Futuro
- Alternativas clicáveis + campo para o cliente acrescentar
- Progresso visual e salvamento local no navegador
- Envio automático das respostas para e-mail ao concluir

## Build

```bash
npm run build
npm run preview
```
